# Hardware

Hardware starts only when live patients show that an important measurement is missing or is not exposed by the devices they already wear.

Until then, Apple Watch, WHOOP, Oura, Fitbit, and Garmin are the sources. A future EVYZ device would be one more source in the same record, not a separate product.

```text
measurement requirement
      ↓
sensor requirement
      ↓
electronics, firmware, enclosure
      ↓
EVYZ band
```

Until that sentence is true, the work is one real history, a personal baseline, and an event a person can recognize.
